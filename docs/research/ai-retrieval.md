| Hashed n-gram fallback is semantic | No supporting source in the inspected official product sources; this is a technical distinction, not a product claim. | Hashing n-grams records overlap of character/token fragments. It does not infer paraphrase, synonymy, or concept-level similarity as learned embeddings do. | Verified distinction; current fallback semantics unknown | Call it “hashed n-gram lexical similarity” or “approximate lexical search.” Avoid “semantic,” “vector embeddings,” and “meaning-based” unless a learned embedding model is actually used. |

## Justified recommendations

1. Keep source path/title/heading with every retrieved item; show citations as clickable cards that open the note.
2. Keep fallback retrieval useful, but label it honestly as lexical n-gram similarity and distinguish it in the UI from semantic embedding search.
3. Report AI/model unavailable plainly and retain non-AI note browsing/search. The inspected Reor source does not verify its current failure-state UI, so this is a recommendation, not a claim about Reor.
4. Expose whether model execution is local or remote; local storage alone does not establish offline operation.
