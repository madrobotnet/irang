## Recommendations supported by evidence

- Implement clear global/local graph scopes; local graph depth and inbound as well as outbound neighbors are evidenced by Obsidian and Quartz.
- Provide graph search/filter and optional group coloring if matching Obsidian's documented controls is desirable; distinguish missing targets explicitly because Obsidian documents both filtering to existing files and creating a missing note, while Quartz's graph source omits targets not in its content index.
- Preserve alternate link display text separately from reusable aliases. Do not claim backlinks, Logseq controls, Quartz keyboard navigation, or alias-resolution specifics based on this evidence.
- Quartz's inspected source imports D3 and Pixi.js. This is direct import evidence for that version only, not a general inference about graph products.
